### 1. `\csname` and `\expandafter` support

- **Item**: `[ENHANCEMENT] \csname ... \endcsname and \expandafter support` (from TODO.md)
- **Why now**: This is the most fundamental gap. `\csname` is used pervasively in LaTeX internals and package code to construct macro names dynamically. Without supporting it, our parser is blind to a whole class of definitions, which is a root cause for many potential "undefined control sequence" errors downstream. This is a prerequisite for correctly parsing many other constructs.
- **Confidence**: HIGH (Confirmed via TeX documentation and widespread use in packages).
- **Test to verify**:
  ```latex
  \documentclass{article}
  \makeatletter
  \expandafter\def\csname my@cmd\endcsname#1{Hello #1}
  \makeatother
  \begin{document}
  \my@cmd{World}
  \end{document}
  ```
- **Blocker for promotion**: This is already a TODO item. The test serves as the acceptance criterion. A failed test (current state) confirms the need to implement.

### 2. `xparse` advanced argument specifiers and conditionals

- **Item**: `[ENHANCEMENT] xparse advanced argument specifiers and conditionals` (from TODO.md)
- **Why now**: `xparse` is now part of the LaTeX kernel, making it a standard for modern command definitions. Our current support is partial, covering only basic argument types. Expanding this coverage to include more specifiers and, critically, the `\If...TF` conditionals used within `xparse` bodies, will dramatically increase compatibility with modern packages and documents.
- **Confidence**: HIGH (Based on `xparse` documentation and its status as a kernel package).
- **Test to verify**:
  ```latex
  \documentclass{article}
  \usepackage{xparse}
  \NewDocumentCommand{\mycmd}{s m}{%
    \IfBooleanTF{#1}{STAR: #2}{NO STAR: #2}%
  }
  \begin{document}
  \mycmd{Hello}
  \mycmd*{World}
  \end{document}
  ```
- **Blocker for promotion**: This is already a TODO item. The test serves as the acceptance criterion. A failed test (current state) confirms the need to implement. Expected output from a successful implementation is `NO STAR: Hello STAR: World`.

### 3. `pgfkeys` / `tikzset` macro definitions

- **Item**: `[ENHANCEMENT] pgfkeys / tikzset macro definitions` (from TODO.md)
