## Step 3 — Ranked list

### MEDIUM/HIGH items

#### Rank 1 — BUG-26: `\tikzset` style definitions stripped (CRITICAL)

- **Why now:** CRITICAL severity — pipeline output fails to compile with
  `! Package pgfkeys Error: I do not know the key '/tikz/curarrow'`.
  Any paper using custom TikZ styles is broken. TikZ is among the most common
  graphics packages on arXiv.
- **Confidence:** HIGH — seen in 1 real arXiv paper; pattern is structural
  (`build_minimal_preamble` has no hook for `\tikzset{...}`).
- **Fix scope:** Add `\tikzset{...}`, `\pgfplotsset{...}`, `\tikzcdset{...}`
  preservation to `build_minimal_preamble`. Requires balanced-brace capture
  (existing `embed_brackets` infrastructure). Also need `\pgfkeys{...}`.

**Minimal test snippet:**
```latex
\documentclass{article}
\usepackage{tikz}
\usetikzlibrary{arrows.meta}
\tikzset{
  curarrow/.style={rounded corners=8pt}
}
\begin{document}
\begin{tikzpicture}
  \node (A) at (0,0) {A};
  \node (B) at (2,0) {B};
  \draw[curarrow] (A) -- (B);
\end{tikzpicture}
\end{document}
```

#### Rank 2 — BUG-27: `\let\cmd\relax` guard stripped (CRITICAL)

- **Why now:** CRITICAL severity — causes `! LaTeX Error: Command \proof already
  defined` on all papers using `llncs`, `beamer`, or similar classes that
  pre-define environments. Affects all LNCS-venue papers (a large share of
  arXiv CS).
- **Confidence:** HIGH — seen in 1 real arXiv paper; fix is narrow and
  well-understood.
- **Fix scope:** Preserve `\let\<cmd>\relax` lines in `build_minimal_preamble`
  when `\<cmd>` matches a known environment name from the preamble. Small fix.

**Minimal test snippet:**
```latex
\documentclass{article}
\newenvironment{proof}{Proof: }{QED}
\let\proof\relax
\let\endproof\relax
\usepackage{amsthm}
\begin{document}
\begin{proof}test\end{proof}
\end{document}
```

#### Rank 3 — BUG-28: `\theoremstyle` stripped (MEDIUM)

- **Why now:** MEDIUM severity — SSIM < 0.85 and 264-line text diff on affected
  papers. Theorem bodies render in italic instead of upright. Visual regression
  is immediately apparent to end users reviewing output.
- **Confidence:** HIGH — structural: `build_minimal_preamble` captures
  `\newtheorem` calls but not interleaved `\theoremstyle` calls.
- **Fix scope:** Capture `\theoremstyle{...}` in the same loop as `\newtheorem`,
  preserving relative order. `\theoremstyle` is sticky — order matters.

**Minimal test snippet:**
```latex
\documentclass{article}
\usepackage{amsthm}
\newtheorem{theorem}{Theorem}
\theoremstyle{definition}
\newtheorem{definition}{Definition}
\begin{document}
\begin{theorem}Theorem body (should be italic).\end{theorem}
\begin{definition}Definition body (should NOT be italic).\end{definition}
\end{document}
```
